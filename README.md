Welcome to Innocent AI, a smart digital assistant designed to help people learn, create, explore ideas and solve problems.

Our mission is to make information and learning easier and more accessible to everyone.

🌟 Features

Innocent AI includes several helpful modes:

- ✨ General Assistant: Get help with everyday questions.
- 📚 Study Coach: Learn school subjects and understand difficult topics.
- ✍️ Writing Studio: Improve writing and create documents.
- 💡 Creative Ideas: Explore new ideas and creativity.
- 💻 Coding Helper: Learn programming and solve coding problems.
- ➗ Maths Helper: Understand mathematical problems step by step.

🎯 Our Mission

To create a helpful AI platform that gives people an opportunity to learn, discover and develop their ideas.

🚀 Getting Started

1. Visit the Innocent AI website.
2. Tap Get Started.
3. Choose your preferred assistant mode.
4. Type your question.
5. Press Send.

🌐 Technology

The website uses:

- HTML
- CSS
- JavaScript
- Optional OpenAI API integration for live AI responses.

📢 Important Notice

The website can be hosted using GitHub Pages for free. However, live AI responses require a separately configured server and API access, which may involve costs.
